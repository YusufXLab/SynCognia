# Empirical Validation

## Core Principle
"The code looks correct" is NOT validation. Every change must be verified with empirical evidence (command output, test output, screenshot) before being marked complete.

## Forbidden Phrases
- "This should work"
- "The code looks correct"
- "I've made similar changes before"
- "It follows the pattern"
